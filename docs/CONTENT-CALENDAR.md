## ⚙️ How the engine uses this file
1. หยิบรายการ `queued` ลำดับบนสุด (หรือเลือกตามเทศกาลที่ใกล้)
2. เขียน `content/blog/NN-slug.md` ตาม template + กฎ "ตอบ 1 ความกลัว"
3. gen รูปฟรี (Gemini) → `content/blog/images/<slug>.jpg`
4. เพิ่ม slug ใน `generate-sitemap.js` → build → review
5. (อนุมัติ) → push main → Vercel + กระจายโซเชียล
6. อัปเดตสถานะในไฟล์นี้เป็น `live`
