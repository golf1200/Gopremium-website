## 1. 🔴 ปัญหาใหญ่สุด — คำว่า "ส่งด่วน" ไม่จริงสำหรับของส่วนใหญ่

การกระจายตัวของ `lead_time` ในของที่ติดธง express:

| lead_time | จำนวน | เป็น "ส่งด่วน" ได้จริงไหม |
|---|---|---|
| 7–10 วัน | 19 | ✅ ใช่ — นี่คือฮีโร่ตัวจริง |
| 10–14 วัน | 6 | ✅ ใช่ |
| 14–20 วัน | 52 | 🟡 "ทันงาน" ได้ แต่ไม่ใช่ "ด่วน" |
| 15–20 วัน | 5 | 🟡 |
| 20–25 วัน | 36 | 🟡 ต้องวางแผนล่วงหน้า |
| 40–60 วันทำการ | 1 | 🔴 **ไม่ใช่ express** |
| "ผลิต 30 วันทำการ / 10,000–15,000 คัน 60 วัน" | 1 | 🔴 **ไม่ใช่ express** |
| "ขึ้นตย.ร่ม 7-10 วัน ผลิต 30 วัน…" | 2 | 🔴 **ไม่ใช่ express** |
| "ใช้ของในสต๊อก 7-10 วันทำการ / สั่งผลิต 30-45 วันทำการ" | 2 | 🟡 ขึ้นกับสต๊อก — ต้องแยกเงื่อนไข |

**ทำไมเรื่องนี้สำคัญก่อนเสียเงินค่าแอด:**
ทั้งกลยุทธ์วางไว้ว่าเราขาย **"ความกลัวข้อ 1 = กลัวมาไม่ทันงาน"** ถ้าจ่ายเงินซื้อคลิกคำว่า "ของพรีเมียมด่วน" แล้วคนคลิกเข้ามาเจอของที่ผลิต 30–60 วัน = จ่ายเงินซื้อคนที่จะผิดหวัง + ผิดกฎ "No fake claims" ใน `website/CLAUDE.md` เอง

## 2. 🔴 `lead_time` เป็นข้อความดิบจากซัพ — เอาขึ้นหน้าเว็บไม่ได้

ตัวอย่างค่าจริงที่อยู่ในฟิลด์ตอนนี้:

```
"-ใช้ของในสต๊อก ระยะเวลาผลิต 7-10 วันทำการ -สั่งผลิต 30-45 วันทำการ
 -ด่วนรบกวนแจ้งวันที่ใช้ และใช้ของในสต๊อค * วันทำการไม่รวมวันหยุดเสาร์-อาทิตย์และนักขัตฤกษ์"

"ขึ้นตย.ร่ม7-10วันผลิต30วันหรือทะยอยส่งขึ้นอยู่กับจำนวน"

"40 -60  วัน ทำการ"
```

เป็นโน้ตคุยกับซัพ ไม่ใช่คำสัญญากับลูกค้า → **filter/sort ไม่ได้ · แสดงผลไม่ได้ · ใส่ schema.org ไม่ได้**

## แผนแก้ (เรียงตามลำดับที่ต้องทำ)

### A. ทำความสะอาดหิ้ง Express — *ทำก่อน ห้ามข้าม*
1. เพิ่มฟิลด์ใหม่ที่ใช้งานได้: `ship_days_min` / `ship_days_max` (ตัวเลข) + `ship_tier`
2. จัดชั้นตามความจริง:
   - **`rush` — ส่งด่วน 7–14 วัน** → **25 SKU** = พระเอกของแอดและ SEO
   - **`ontime` — ทันงาน 14–20 วัน** → 57 SKU
   - **`plan` — วางแผนล่วงหน้า 20–25 วัน** → 36 SKU
   - **ถอดธง express ออก** → 6 SKU ที่ผลิต 30–60 วัน (ย้ายไปแคตตาล็อกปกติ)
3. เก็บข้อความดิบจากซัพไว้เป็น `lead_time_note` (ภายใน) ไม่แสดงหน้าเว็บ
4. เติมราคา 6 SKU: **EX056, EX057, EX058, EX059, EX060, EX061**
5. ผูก `occasions` ให้ Express ทุกตัว (map จาก category + ราคา)

### B. หน้า `#/express` ให้เป็นหน้าทำเงิน
คำสัญญาชัดหัวหน้า · ฟิลเตอร์ "ต้องใช้ภายในกี่วัน" · badge วันส่งรายชิ้น · FAQ + `FAQPage` schema · CTA เดียว

### C. เครื่องมือวัดผล — ก่อนเปิดแอด
Google Ads tag + GSC + conversion event "ส่งฟอร์มขอใบเสนอราคา"

### D. เปิด SEM แล้วค่อยตามด้วย SEO/social
ยิงแอดเข้า `#/express` เท่านั้นในรอบแรก (หน้าที่คำสัญญาแรงสุด + วัดผลง่ายสุด)
